## 2. Phase 1：大陆形态革命（P0，约 60% 工作量）

### P1.1 超大陆旋回（plate_sim.py v3.0）——核心重构

**现状问题**：`run_plate_sim` 中 12 板块随机旋转轴+角速度（L158-162），大陆播种为随机圆盘并集（L172-193），450 Myr 自由漂移 → "blob 大陆"，无历史遗产。

**设计**：将 720 步划分为三阶段，速度场按阶段构造：

```
t ∈ [0, 150 Myr)   聚合期：所有板块朝"聚合中心"大圆漂移
t ∈ [150, 260 Myr)  超大陆期：碰撞高峰，orog 大量累积；地幔保温 → 裂谷种子萌发
t ∈ [260, 450 Myr)  裂解期：超大陆沿 2-4 条放射状裂谷线分开，新洋盆对称张开
```

**算法细节**：

1. **聚合速度场**（替换 L158-162 随机 axes/omg）：
   - 随机聚合中心 `c`（单位球面向量，85% 概率偏向陆半球极轴）
   - 每板块 k 取其大陆质心 `p_k`（无大陆板块保留随机漂移）
   - 旋转轴 `axis_k = normalize(p_k × c)`，角速度 `omg_k = angle(p_k, c) / 150Myr`（限幅 [0.001, 0.005]）
   - 叠加 10% 随机扰动 `+ 0.1·U(-ω,ω)` 防完全对称汇聚
   - 后向映射搬运框架（L220-227）不变，只换速度来源

2. **微大陆/地体**（新增，聚合期撒 4-8 块）：
   - 独立小陆块 r=4~9 cells，速度朝聚合中心但延迟出发（t>60Myr 启动）
   - 晚到者撞入超大陆边缘 → **印度型撞入半岛**（crust 并入 + orog 局部累积）
   - 途中搁浅者 → **马达加斯加型大陆岛**

3. **裂解期速度场**（t=260 时重置）：
   - 对超大陆连通域取骨架，选 2-4 条穿过内部的裂谷线（从内部热柱点放射）
   - 裂谷线两侧赋予分离速度：垂直裂谷线、两侧反向、量级 U(0.0015, 0.004)
   - **关键新增输出 `rift_margin` 掩膜**：裂解启动时刻，与新洋壳（age=0）相邻的大陆像素标记为"被动边缘"；该掩膜随板块搬运（同 crust 机制）
   - 洋壳年龄机制天然产生对称张开：裂谷线 age=0，向外变老 → 中洋脊居中 + 两侧海岸形状互补（**拼图边缘**，非洲-南美型）

4. **边缘类型终局判定**（新增输出 `margin_type` 场，0=被动 1=主动）：
   ```
   passive: rift_margin 标记 & 现仍邻海 & d_trench > 3px
   active : d_trench < 3px（俯冲边缘）
   ```
   传给 generate_world 的 `ocean_margin_fix`：被动边缘宽陆架（140km，大西洋型），主动边缘窄陆架（30km）+ 崎岖海岸（太平洋型）。

**风险与对策**：
- 聚合可能使陆地过度堆积 → 聚合期结束校验：超大陆连通域占陆地 <75% 则对最远碎片施加额外漂移
- 裂解后陆地占比漂移 → `land_target` 保护机制（L247）已有，保留
- 缓存版本升级 `plate_sim_v3_T{res}_seed{seed}.npz`

**预期**：大陆轮廓 5 分→7 分；构造历史遗产 3→7 分；被动/主动边缘分化为 P1.3/P3.1/P2.1 提供接口。

### P1.2 造山带延展算法（plate_sim 终局装配 + generate_world 骨架）

**现状问题**：`orog` 累积自碰撞边界（L253），512 格下碰撞边界是短弧段 → 山地斑块化；`mt = tanh(gaussian_filter(orog,3)/o_s)`（L321-322）各向同性平滑无法连接碎块。v6.6 板内造山只补 1-2 条且偏短。

**设计**：多方向定向形态学闭运算把碎块沿走向焊接成带：

```python
# plate_sim 终局装配, 替换 mt 计算前插入:
# 1. 山核掩膜: orog > 分位阈值 q80
core = orog > np.quantile(orog[orog>0], 0.80)
# 2. 多方向线状闭运算: 6 个方向 (0°..150°), 线核长 11px
#    closed_θ = binary_closing(core, line_kernel(θ, L=11))
#    closed = OR over θ   → 碎块沿任意走向被焊接
# 3. 延展后的 orog: orog_ext = max(orog, 0.35·o_s · closed)
# 4. belt 骨架场: 对 closed 距离变换 d_axis
#    mt = tanh(orog_ext / o_s) · ridge_profile(d_axis)   # 主脊居中、向两翼衰减
```

**generate_world 配合**（L204 山脉公式）：
- `envS`（构造场）替换为上采样 `belt` 场：山带内 `ridged_fbm` 沿垂直走向调制 → **主脊-支脉-山前丘陵三级结构**
- 骨架公式改造：`700m × belt × wvar × ridged² · (0.55 + 0.45·exp(-(d_axis/w)²))` → 带中央主脊高、两翼低
- 走向各向异性：`d_axis` 上采样后山带宽度沿走向变化（wvar 场已有，保留）

**验收**：belt_share（AR>3 山地面积占比）19% → ≥55%；每图至少一条纵贯大陆（长度 > 大陆长轴 60%）的主山带。

### P1.3 裂谷系统（plate_sim 终局装配 + 渲染层）

**现状问题**：`div_mem` 裂谷记忆（L254-256）被陆地保护机制（L247-251）拦截后**不留任何地貌痕迹**——失败裂谷（aulacogen）地貌完全缺失；v2.1 的弧后盆地项（-420m 弱信号）在 v2.2 重标定时被删除。

**设计**：

1. **失败裂谷/古裂谷**（东非型）：
```python
# 曾强烈离散但未裂开的区域: div_mem 累积 > 15 Myr 且仍为陆壳
failed = (div_mem_total > 15) & crustm
# 沿 failed 高值带取轴线 (细化) → d_axis = 距轴距离
e_ld -= 900 · exp(-(d_axis/1.2)²)                    # 谷底线性洼地
e_ld += 350 · exp(-((d_axis-2.2)/1.5)²)              # 双侧肩部抬升
e_ld += 2600 · axial_volcanics · (rng < 0.25 沿轴)    # 裂谷火山链 (乞力马扎罗型)
```
   串珠湖：谷底局部极小由现有 `fill_depressions` 自动成湖；加深阈值使裂谷湖可见。

2. **弧后盆地**（日本海型，复活 v2.1 项并加强）：
```python
e_oc -= 1800 · exp(-((d_tr - 8.0)/4.0)²) · (~crustm)   # 岛弧后方 500~900km 半深海
```
   与 v2.2 年龄分位映射兼容：该项在映射**之后**施加（局部扰动不改全局直方图骨架），或把 `ocean_margin_fix` 的豁免带加宽覆盖弧后区。

3. **前陆盆地配对强化**：现有 `fore` 项（L325-330）幅度 -620m → 改为 `orog` 延展后的 `belt` 场配对：`e_ld -= 800 · tanh(2·belt_outer)`（恒河平原型紧贴山麓），确保 P1.2 延展后前陆盆地随山带连续。

## 3. Phase 2：气候系统升级（P1）

### P2.1 简化海洋环流（terrain_engine.py 新增 `ocean_current_field`）

**现状问题**：`temperature_field`（L780）只有纬度+海拔+极地放大；`precipitation_field`（L793）固定盛行风向。缺失：湾流/黑潮型西边界暖流、加那利/秘鲁型东边界寒流、北大西洋暖流的欧洲增温。

**设计**（静态场，渲染前一次性计算）：

```
1. 洋盆识别: ocean 连通域 > 全球 5% → 大洋盆地列表
2. 每盆地每纬度带求东西边界 → 西边界流带 (盆地西缘东侧 2~4px)
   北半球顺时针环流 / 南半球逆时针 (科氏力)
3. 暖流标签 warm: 西边界流带 + 其向极延伸 (至 55°); 
   若盆地北端闭合且延伸达 45°+ → "北大西洋暖流型" 长臂
4. 寒流标签 cold: 盆地东缘 (大陆西岸) 副热带段 (10°~35°)
```

**气候修正**（`temperature_field`/`precipitation_field` 增加参数 `current_adj`）：
```
暖流邻陆 (≤400km):  T += 3.5°C · exp(-d/300km);  P += 450mm · exp(-d/400km)
寒流邻陆 (≤400km):  P *= 0.55;  T -= 1.5°C · exp(-d/300km)   → 阿塔卡马/纳米布型荒漠强化
暖流 + 40°~60° + 西风迎风 → P += 800mm → 触发温带雨林 (whittaker 表已有该群系, 现仅 0.3%)
```

**效果**：欧洲型暖湿西岸、寒流海岸荒漠、温带雨林占比 0.3%→1.5%+（地球 0.34%）。

### P2.2 季风系统（`precipitation_field` 扩展）

**设计**：
```
大陆度指数: C(lon) = 该经度 ±15° 窗口内热带 (0~35°) 陆地占比
季风降水: 热带沿岸 (距海 < 1500km) & 5°~28°:
   P_monsoon = 1400mm · C · exp(-d_coast/900km) · exp(-((|lat|-15°)/12°)²)
年均合成: P_total = P_zonal·w + P_oro + P_monsoon (季风雨季集中 → 年均权重 0.55)
```

**效果**：稀树草原→季风雨林转化，热带雨林占热带陆地 4.7%→7%+；南亚/东南亚型雨林带涌现。

**依赖**：P1.1 的拼图大陆提供"大型热带大陆"形态（季风需要广阔陆块才显著）。

## 4. Phase 3：地貌细节（P2）

### P3.1 半岛生成（三种机制）

| 类型 | 机制 | 实现位置 |
|---|---|---|
| 印度型撞入半岛 | 微大陆晚到聚合（P1.1 微大陆机制） | plate_sim v3.0 |
| 斯堪的纳维亚型 | 高纬被动边缘 + **峡湾雕刻**：极地 (|lat|>55°) 被动边缘海岸，从海岸点向内陆随机游走刻窄谷 (宽1-2px, 深-80~-300m, 长4-10px, 分叉2级) | generate_world 新增 `carve_fjords` |
| 阿拉伯/佛罗里达型 | 被动边缘宽陆架台地：`land_hist_final` 后对被动边缘 -50~+80m 台地保形（海平面微调 ±15m 使台地露头成半岛） | generate_world |

**陆间海**（地中海型）：聚合期残留洋盆（两块大陆几乎闭合但未焊死的缝隙，宽 2-5px 海洋带）→ 裂解记录 + 终局保留；渲染为半封闭浅海。

### P3.2 冰盖动力学（terrain_engine 新增 `ice_sheet_model`，替代阈值雪盖）

**现状问题**：`polar_ice_mask` + 渲染层雪线阈值 → 雪盖碎片化、冰下地形纹理可见。

**设计**：
```
1. 冰盖掩膜: |lat|>58° & T<-6°C & 陆地连通域 > 陆地 2%（南极型）
   或 高纬高地 (格陵兰型: T<-9°C & elev>1000m 连通域)
2. 下伏地形平滑: σ=8px 高斯（冰盖抹平效应）
3. 冰穹: 每个冰盖区取分冰岭（平滑后最高点）
   ice_surface = divide_elev - k·dist_to_divide^1.15  （穹状）
4. dem_ice = max(dem_smoothed, ice_surface)  仅冰盖区内
5. 渲染: 冰盖区整体连续白色（不依赖雪线阈值）；冰盖边缘海冰带加宽
6. 峡湾: 冰盖边缘 500km 内海岸调用 P3.1 carve_fjords
```

**直方图兼容**：`_LAND_V`/_LAND_W_V 本身含南极+格陵兰冰盖高程——冰盖像素在 `land_hist_final` 中**豁免**（不参与重排），保持穹状形态；非冰盖陆地单独重排。

### P3.3 珊瑚礁带（generate_world 新增 `add_coral_reefs`）

```
条件: |lat|<28° & -60m<elev<0 & 海表T>20°C
环礁: 满足条件浅海以 ~12% 概率抬升小岛（峰 3~8m, r=1~2px, 群集 3-8 个成礁盘）
渲染: 礁盘浅海绿松石着色（cmap 浅海带扩展）
```

**大陆岛补强**：`add_island_arcs` 之外，被动边缘陆架上（P1.1 margin_type=passive & 陆架带内）以低概率盖章残留高地小岛（不列颠/新西兰型）。

## 5. 不回归保障（统计校准守护）

所有新地貌必须过校准层的"容错门"：

| 校准层 | 兼容策略 |
|---|---|
| `land_hist_match/final` | 冰盖像素豁免；半岛/岛屿高程参与重排（数量小不破坏直方图） |
| `_OC_V` 海洋分位映射 | 弧后盆地/陆间海在映射**之后**局部施加 |
| `ocean_margin_fix` | 升级为 per-margin-type：被动宽陆架/主动窄陆架双参数 |
| `despeckle(min_area=32)` | 保持；珊瑚/大陆岛盖章后不再去斑（顺序：盖章在 despeckle 之后） |
| GAN 12 通道 | belt 场替换 envS 通道语义不变（数值域一致，无需重训） |

**回归测试协议**：每阶段完成 → `batch_gen.py` 3 种子快检 + `analyze_worlds.py` 对比 v6.6 基线（`analysis_results.json` 已存档）→ 统计校准八项任一劣化 >10% 即阻断合入。

## 6. 验收标准与新增指标

`analyze_worlds.py` 新增函数：

```
count_peninsulas(dem):   陆地连通域骨架端点, 长宽比>3 且基部宽>8px 的陆岬 → 每图 ≥3
count_rifts(dem):        线性洼地 (长>40px, 宽<8px, 深>500m) 连通域 → 每图 ≥1
ice_sheet_continuity(dem): 极地陆地最大冰盖连通域 / 极地陆地 → ≥0.75（南极连续性）
monsoon_forest_share:    季风指数区雨林占比
belt_share / largest_basin_share / n_islands: 沿用现有
```

**最终验收**（10 种子均值）：
1. 0.2 节量化指标全部达标
2. 雷达图 12 维无任何维度低于 6 分
3. 视觉检查：每图可见 ①纵贯山带 ②裂谷或陆间海 ③至少 3 半岛 ④连续极地冰盖 ⑤暖流西岸森林/寒流西岸荒漠对比

## 7. 实施顺序与里程碑

