# 幻想世界生成器 v9.0 —— 技术文档

> 使用说明见 [README.md](README.md)。本文档面向算法原理与调参。

## 1. 管线总览

```
板块演化模拟 (plate_sim v3.0 超大陆旋回, 450 Myr)
    ↓  粗DEM + 4构造场 + 陆壳场 + margin_type(被动/主动边缘)
周期 fBm 域扭曲 (消 Voronoi 直线感)
    ↓
像素级骨架细化 (海岸分形级联 / 山脉束状 / 盆地)
    ↓
v6.6 检验修复层 (陆架剖面 per-margin / 陆地直方图 / 板内造山 / 岛弧 / 热点)
    ↓
12 通道条件 → 逐瓦片 GAN (UNet) 细节生成
    ↓
全局后处理 (CDF 匹配 → 去斑 → 水力侵蚀 → 干流雕刻 → 陆架/直方图终检)
    ↓
v8.3 河流水系系统 (骨架提取 + 沿程单调修复 / Hack 定律蜿蜒 / 牛轭湖 / 连续蓝度渲染)
    ↓
气候因果链渲染 (温度→降水→生物群系 / 河湖 / 雪线 / 海冰)
    ↓
v9.0 监督反思 (supervisor 审计 → 反思 → 学习日志 → 自动注入 overrides)
```

运行（项目根目录）: `python terrain/generate_world.py --seed 0 --size 2048`
板块模拟单独调试: `python terrain/plate_sim.py --seed 7 --T 512`
重训 GAN: `python terrain/terrain_engine.py`（需 data/ 中的 ETOPO1）
重绘（不重算 DEM）: `python terrain/rerender.py`

> 所有路径基于脚本所在目录（terrain/），从任意工作目录调用均有效。

## 2. 板块演化模拟 (plate\_sim.py v3.0 超大陆旋回)

### 原理

球面前向模拟：K 个板块各持旋转轴与角速度，每步后向映射搬运地壳。
**v3.0 三阶段速度场**（450 Myr = 720 步）：

| 阶段   | 时间          | 速度场                                                   | 目标             |
| ---- | ----------- | ----------------------------------------------------- | -------------- |
| 聚合期  | 0–150 Myr   | 差速收敛: 各板块朝聚合中心 c 大圆漂移 (omg=角距/(horizon·dt))           | 大陆汇聚           |
| 超大陆期 | 150–260 Myr | 持续朝心挤压 + **焊接缝合**(接触≤2px 的板块并入, 滞留板块豁免)               | 单一超大陆, orog 高峰 |
| 裂解期  | 260–450 Myr | 主裂谷(260Myr)+次裂谷(340Myr): **共享欧拉轴对旋** (e=a×pc, ±om\_s) | 大西洋型对称张开       |

### v3.0 关键机制

| 机制              | 实现                                         | 解决的问题                   |
| --------------- | ------------------------------------------ | ----------------------- |
| 聚合中心            | 热带边缘 \~27°纬 (z=0.45), 偏向随机陆半球              | 大陆纬度分布 (盘古跨赤道布局)        |
| 滞留板块            | 1-2 个 Voronoi 领土达极地的板块不参与聚合, 极地陆量保底 ≥12%   | 南极/格陵兰型极地大陆+冰盖          |
| 微大陆/地体          | 4-6 块小陆块延迟出发 (t>100Myr) 朝 c 撞入             | 印度型撞入半岛/马达加斯加型大陆岛       |
| 板块切割            | 沿裂谷大圆切最大陆板块, 轴向搜索(12候选, 两侧≥25%陆)           | 超大陆裂开成新板块               |
| 预挖海峡            | 切线两侧 ±2px 全部陆地清除                           | 切线端点零间隙 → warp/对跖线桥接    |
| 共享欧拉轴对旋         | 两块绕同一轴(e=a×pc)反向旋转 ±0.0045 rad/步, 速度锁定     | 各自独立旋转会在球面回摆重触(对跖线桥接根因) |
| 陆地全局守恒          | 后向映射取整的复制/湮灭对称增删: 凹湾补/岬角删(平滑海岸), 裂解期排除裂谷缝隙 | 陆地面积恒定 + 海岸去噪 + 裂谷不被填死  |
| 陆地硬约束           | >33% 时海岸腐蚀剥皮到 \~30%                        | 守恒残余漂移                  |
| margin\_type 输出 | 被动(近脊无沟=大西洋型)/主动(海沟=太平洋型)边缘掩膜              | 下游 per-margin 陆架分化      |

### 边界分类规则

相邻格速度差在边界法向投影 `cn`：

- `cn > 0.35·|v|` 汇聚：陆陆→碰撞造山；洋陆→海沟+火山弧；洋洋→老洋壳俯冲

- `cn < -0.35·|v|` 离散：洋洋→洋中脊；陆陆→裂谷（衰减记忆 \~37 Myr 后裂开）

- 其余 → 转换断层

### 关键参数

| 参数                                      | 值                             | 说明               |
| --------------------------------------- | ----------------------------- | ---------------- |
| `T`                                     | 512                           | 模拟分辨率 (格)        |
| `K`                                     | 12 (+4-6 微大陆, 板块号池 MAXP=K+16) | 板块数              |
| `dt × steps`                            | 0.625 × 720                   | 450 Myr 总演化时长    |
| `land_target`                           | 0.31                          | 目标陆地占比           |
| `step_agg_end / step_rift / step_rift2` | 240 / 416 / 544               | 三阶段切换步           |
| `om_s`                                  | 0.0045 rad/步                  | 裂解对旋速度 (\~30°/侧) |

### 地形赋值（终局装配, v2.2 海洋直方图标定）

- **开阔洋**: 洋壳年龄**排名** → 地球开阔洋深度分位（\_OC\_Q/\_OC\_V, ETOPO1 实测）。
  单调映射保持空间结构：活跃脊=最年轻=最浅，俯冲前缘=最老=最深
  → 洋中脊体系与深海平原面积占比天然对齐地球

- 陆架/陆坡: 距陆剖面强制（陆架 0→-140m/80km，坡 →-1800m，陆隆 →-4400m 渐出）

- 海沟: 俯冲带窄带剖面 `-(5700+700·速率) − 2600·exp(-(d/0.8px)²)`，带宽≈100km

- 火山弧: 1500m 基座 + 4600m 峰值 × 低频门控（弧段链，非圆点）

- 热点: 记忆场高门槛(>0.35)抬升 → 只造零星岛链，不淹没洋盆

- 碰撞造山: 历史累积 orog → tanh 压缩 → 峰值 \~4900m

- 前陆盆地: 造山带外侧 −620m（山盆成对）

## 3. 域扭曲 + 骨架细化 (generate\_world.py)

### 周期 fBm 域扭曲

```
offset = 16·fbm(freq=6, oct=3) + 4·fbm(freq=20, oct=2)   # 单位: 格
```

高程/构造/陆壳三场**同步扭曲**（保持空间一致），经度方向回卷无缝。
→ Voronoi 直线边界变自然弧线，消"细胞壁"感。

### 海岸分形级联（D≈1.3）

海岸带 = `exp(-(|elev|/420m)²)` 内逐级叠加：

| 层级  | 振幅   | 频率    | 效果    |
| --- | ---- | ----- | ----- |
| 宏观  | 480m | 连续陆壳场 | 大湾/半岛 |
| 中观  | 300m | f=34  | 岬角/海湾 |
| 细观1 | 150m | f=90  | 岸线弯曲  |
| 细观2 | 85m  | f=200 | 碎屑岸   |
| 细观3 | 45m  | f=450 | 像素级粗糙 |

### 山脉与盆地

- 山脉: `700m × 构造场 × 宽度变化场(0.25~2.0) × ridged_fbm²`
  （束状分支 + 宽度空间变化，消"贴边条"）

- 山间盆地: `−2000m × 低频噪声(f=10) × 造山带强度`（费尔干纳型）

- 腹地盆地: `−1600m × 距岸>130px × 低频噪声`（刚果/塔里木型）

### v6.6 检验修复层（骨架尾部, 基于 10 种子七维地理检验）

基于 ETOPO1 实测分位数（\_LAND\_V 未加权 / \_LAND\_W\_V cos 纬度加权）：

| 修复       | 函数                      | 解决的偏差                                                |
| -------- | ----------------------- | ---------------------------------------------------- |
| 陆架-陆坡剖面  | `ocean_margin_fix`      | 陆架缺失（0.7%→6%）: 近岸 140km 剖面强制，俯冲带/深渊豁免                |
| 陆地直方图重映射 | `land_hist_match`       | GAN"回归均值"（89% 陆地挤在 200\~1000m）→ 28% 平原/46% 台地/26% 山地 |
| 板内造山带    | `add_intraplate_orogen` | 山地 100% 锁定俯冲带（地球过半山地在板内）: 大陆内部 1\~2 条板内山             |
| 岛弧链      | `add_island_arcs`       | 岛屿贫乏（23→77+ 个）: 俯冲带大陆侧 180\~340km 盖章链状群岛             |
| 热点岛链     | `add_hotspot_chains`    | 夏威夷型洋中岛链（3\~6 条）                                     |

## 6. 气候因果链 (terrain\_engine.py)

### 温度场（v7.0 基础 + v7.1–v7.4 改进）

```
T = 27 − 0.42·|lat| − 6.5·(elev/1000) − 22·clip((|lat|−55)/35, 0, 1)²
```

末项为极地放大 → 80° 海平面约 −15°C，极冠自动成雪。

**v7.1+ 温度改进**（`continentality_index` 大陆度指数 + 极地过渡软化 + 副热带高压绝热增温）：

| 改进项 | 机制 | 解决的问题 |
| --- | --- | --- |
| 大陆度指数 CI | `CI = (1−exp(−d_sea/1800km)) × (0.55+0.45·clip((|lat|−15)/75,0,1))` | 深内陆冬季更冷（西伯利亚型），修正纯纬向温度 |
| 极地过渡软化 | `polar = clip((|lat|−58)/32, 0, 1)^1.5 × 22`（v7.1 缓和版） | 66.5° 一刀切 → 66–72° 苔原低地保留（泰加林生存窗口） |
| 副热带高压 | 20–32°（25° 峰 +2.3°C）绝热下沉增温 | 副热带荒漠带温度对齐地球 |
| 深水汽输送 | v7.1 尾项：距海 >600km 的内陆降水尾效衰减 | 大陆腹地干旱梯度更自然 |

**v7.3/v7.4 极地校准**（P-POLAR v7/v8）：58°+ 大陆冬天冷化豁免 40%→60%，
解决用户报告的"泰加林缺失，60°N 几乎全是苔原"问题。

### 降水场（v7.0 基础 + v7.1+ 六重改进）

纬向基础（ITCZ 峰 2300mm → 副热带谷 520 → 温带 850 → 极地 130）
× 盛行风向扫描（30°\~60° 西风带东向；其余信风/极地东风西向）：
迎风坡地形雨 ≤2600mm，水汽随陆上路径指数衰减
→ **雨影荒漠与大陆腹地干旱自动涌现**。

**v7.1 降水六重改进**（对应用户报告的 6 大气候问题）：

1. 纬向基础降水保留，叠加 5 层修正
2. 大陆度 CI 惩罚：深内陆降水打 `(1−0.55·CI)` 折（中亚戈壁型）
3. v7.3 分纬度带 CI 权重分化（解决"右侧大陆纵贯荒漠"异常）
4. v7.4 赤道 |lat|<15° CI 惩罚放宽 0.80→0.50（地球 ITCZ 对流雨局地性）
5. 山脉破碎扰动（±12% 相对，仅 800m+ 山带激活）
6. v7.2 气候计算用 σ=2.2 高斯平滑地形，消除 ridged_fbm 脊状高频与纬向 T 的拍频伪影

### 洋流/季风异常场（v7.0-M4, `ocean_current_effects`）

在 (T, P) 上叠加海岸几何驱动的四类异常（详见 §13）：
暖流 dT+dP（大陆东岸 30-60°）、寒流 −dP（西岸 5-35°）、
季风 +dP（东岸 5-28° 大陆）、西风带雨林 +dP（西岸 38-62°）。

### Whittaker 生物群系（9 类）

(T, P) 查表: 苔原 / 针叶林 / 温带草原 / 落叶林 / 温带雨林 /
亚热带荒漠 / 稀树草原 / 热带季节林 / 热带雨林

### 雪线（双因素）

- 纬度曲线: 赤道 4800m → **副热带 25° 峰值 5800m**（安第斯型）→ 极地 0m

- 干旱抬升: `+800m × (1 − P/700)`（降水越少雪线越高）

- 温度雪线: 年均温 ≤ −12°C 常年积雪（连续过渡，无硬截断）

## 7. 渲染 (render\_world) + v8.3 河流水系

### 基础渲染要素

| 要素   | 实现                              |
| ---- | ------------------------------- |
| 陆地配色 | 生物群系色 × 海拔明暗 × NW 光照山体阴影        |
| 湖泊   | 填洼面−实际地形 > 0.012 → 深蓝           |
| 河流   | 流累积 > 99.5 分位；干流 (>5×阈值) 加宽更深的蓝 |
| 雪盖   | max(纬度雪线, 温度雪线) × 山脊骨架纹理        |
| 海冰   | 64.5°±2.5° 纬度 + 浮冰噪声            |

### v8.3 河流水系系统（`extract_river_skeleton` / `carve_rivers` / `paint_rivers_rgb`）

在 v6.6/v7.0 干流雕刻基础上，v8.3 对河流水系做了系统性升级，解决了
"河流像直线"、"流量沿途不单调"、"颜色生硬"三大问题。

| 子系统 | 关键机制 | 解决的问题 |
| --- | --- | --- |
| **骨架提取 + 单调修复** | D8 流累积 → 阈值化 → 细化骨架 → 4 pass 广搜修复沿程流量单调（`R=1→2→3` 邻居） | `log(acc)` 单调比 0.62 → ≥0.92，支流不出现逆流 |
| **Hack 定律蜿蜒** | 摆幅 `amp ∝ A^0.50`（A=汇水面积），5 轮转弯钳制，Sinuosity 闭环 | 短骨架(L3/L4 源头支沟)不大弯；主流 2.63× / 源头 0.25× 摆幅梯度 |
| **Hack 幂律宽/深** | 河宽 `W ∝ A^0.5`，深槽偏摆 + 中心 V 深切 + 非对称深槽 | 大河宽深、小河窄浅，符合 Hack 定律 |
| **牛轭湖截断** | 高弯曲段河道裁弯取直，旧河道残留为牛轭湖（淡染） | 自然河曲地貌 |
| **连续蓝度渲染** | 距离场羽化岸线（2\~3px 真羽化，消除像素锯齿）+ 交汇色溢 + 牛轭湖淡染 | v8.2 视觉硬边界 / 单调三档 / 交汇无色溢 |

渲染调用链：`climate_flow_accumulation` → `extract_river_skeleton` →
`carve_rivers`（地形下切）→ `paint_rivers_rgb`（RGB 着色）。

### v7.1 极地冰盖渲染（`polar_ice_mask` / 冰盖渲染）

v7.0 的 66.5° 一刀切全冰 → v7.1 改为 66.5°→72° 过渡带，仅
`elev > (雪线−400m)` 的极地平顶强制雪，低地保留苔原色。
冰盖区整体连续白色（不依赖雪线阈值），冰盖边缘海冰带加宽。

## 16. WorldGeoContext 单例 (geo\_context.py, v7.0 新增)

面向"后续消费 DEM 数据"的统一查询入口。避免每个调用方都手动 `numpy.load('world_dem.npy')` + 写坐标换算 + 双线性插值。

### 16.1 设计原则 —— Singleton + Protocol + 懒加载

```
调用方 → get_ctx(seed, size)
            └─▶ WorldGeoContext.from_seed(seed, size) [单例: 同 seed+size 永远返回同一对象]
                    │
                    ├─ 1) 检查 output/ 下是否有 world_dem.npy 同 seed+size
                    │     · 有 → np.load 懒加载 (首次访问 .dem 才真正读入内存, ≈16MB/2048²)
                    │     · 无 → 调用 _generate_world_safe() 启动 generate_world 管线 (约 2-4 分钟)
                    ├─ 2) 计算 lat/lon 网格轴 + _GEO_BOUNDS (-11000 ~ 9000m, 非 inf)
                    └─ 3) 缓存 slope 场（deg→km 坡度, 用 cos(lat) 对经度微分做地球球面校正）

外部替换地形引擎：实现 TerrainDataProtocol（get_elevation / get_slope / latlon_to_idx 等 8 个方法）
即可无缝替换 WorldGeoContext，可视化 / 分析 / 导出工具链零改动。
```

### 16.2 核心数据

| 字段                              | 形状 / 类型                 | 说明                                                           |
| ------------------------------- | ----------------------- | ------------------------------------------------------------ |
| `.seed` / `.size` / `.dem_path` | int / int / `Path`      | 生成参数 + 实际 DEM 路径                                             |
| `.dem`                          | `(S, S)` float32, 米制    | 高程（懒加载）。正值陆地 / 负值海洋；行 0 = 北纬 90° − 半格距，行 S−1 = 南纬 −90° + 半格距 |
| `.slope_field`                  | `(S, S)` float32, **度** | 坡度（懒计算）。0°=平地，45°=1，90°=悬崖                                   |
| `.geozone`                      | `(S, S)` uint8          | 地理带分级（见 §7 生物群系 + 海沟/洋中脊掩膜组合）                                |
| `.crust_type`                   | `(S, S)` uint8          | 陆壳(1) / 洋壳(0)                                                |
| `.lats` / `.lons`               | `(S,)` float64          | 每行/列对应的经纬度（与 DEM 像素中心对齐）                                     |

### 16.3 坐标转换约定

所有转换都走**像素中心 → 地理坐标**的一一映射（`round` 而非 `floor`，保证 `latlon_to_idx(idx_to_latlon(r, c)) == (r, c)` 严格往返）。

```
行 r ∈ [0, S−1]  →  lat(r) =  90 − (r + 0.5) × 180/S     (北半球在 r 小时)
列 c ∈ [0, S−1]  →  lon(c) = −180 + (c + 0.5) × 360/S     (经度 0° 在 c≈S/2)
```

**常见坑：r=0 行是北半球 (lat=+90°−half\_pixel)**。NumPy 数组的「从上到下」正好对应地球「从北极到南极」：`.dem[0, :]` 是最靠近北极点的一行（北纬 90° 减去半个像素），`.dem[S-1, :]` 是最靠近南极点的一行（南纬 −90° 加上半个像素）。如果你把 `r=0` 当成南极，南北极会完全搞反，雪盖/苔原跑到赤道、热带雨林冻成冰原。可视化时 `plt.imshow(dem)` 默认原点在左上角，因此地图自动「上北下南」是正确的，不用额外 `np.flipud`。

### 16.4 关键 API

| API             | 签名                                                                         | 说明                                                                       |
| --------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| `get_ctx()`     | `get_ctx(seed=0, size=2048) -> WorldGeoContext`                            | 便捷入口：等价 `from_seed`，缓存 100%                                              |
| `from_seed()`   | `classmethod from_seed(seed, size, force_reload=False) -> WorldGeoContext` | 单例构造                                                                     |
| `reset()`       | `classmethod reset()`                                                      | 清掉单例（跑测试 / 强制重算时用）                                                       |
| `latlon_to_idx` | `(lat, lon) -> (r, c)`  int                                                | 经纬度 → 最近像素行列（round）                                                      |
| `idx_to_latlon` | `(r, c) -> (lat, lon)`  float                                              | 像素行列 → 中心点经纬度                                                            |
| `get_elevation` | `(lat, lon) -> float 米`                                                    | **双线性插值**，任意连续经纬度                                                        |
| `get_slope`     | `(lat, lon) -> float 度`                                                    | 同上，球面校正后的坡度                                                              |
| `is_land`       | `(lat, lon, threshold=0.0) -> bool`                                        | 是否陆地（默认 ≥ 0m）                                                            |
| `region_stats`  | `region_stats(polygon: List[(lat,lon)]) -> dict`                           | 多边形内统计：点数 / 陆地占比 / 洋壳% / 山地% / 平均海拔 / 最大海拔                               |
| `summary_stats` | `property -> dict`                                                         | 全球 KPI：`land_ratio, mont_ratio, peak, trough, ...`（与 HTML 报告 7 张 KPI 同源） |

## 21. 深度学习模块 (terrain/dl/, v9.0 新增)

> 与 `terrain/core/` 的 **12 通道条件 GAN（UNet）** 是两条独立路线：core/ 的 GAN 是项目主生成器（内置权重、开箱即用）；`terrain/dl/` 是新一代扩散模型路线（DDPM → LDM → 物理监督 → 大规模推理 → 端到端管线），用于研究与下一代生成器替换。

### 21.1 五阶段路线图

| --- | --- | --- | --- |
| **1** | 数据 + 无监督 DDPM | `dataset.py`, `vae.py`, `unet.py`, `diffusion.py`, `train.py`, `metrics.py`, `evaluator.py` | DEM 切片数据集 + VAE（256²×1 ↔ 32²×4 潜空间）+ DDPM 去噪 U-Net + 余弦调度 + EMA + 周期采样评估 |
| **2** | 半监督条件扩散 LDM | `paired_dataset.py`, `train_ldm.py`, `ddim.py`, `infer_ldm.py` | 少量配对样本训练条件 LDM，DDIM 采样加速，分块推理 |

### 21.3 端到端管线 (pipeline.py)

```
统计校准 (直方图匹配 + 陆地占比保护)
```

**关键特性**：`PipelineConfig` 集中管理参数（支持 YAML）、条件缓存（同 seed 复用板块模拟）、阶段控制（选择性跳过/重试）、错误降级（SR/物理失败时降级到原始 DEM）、进度回调。

```python
from terrain.dl.pipeline import DiffusionPipeline, PipelineConfig
cfg = PipelineConfig(seed=42, size_px=4096, use_sr=True)
pipe = DiffusionPipeline(config=cfg)
dem, info = pipe.generate(progress_callback=lambda pct, msg: print(f"{pct:.0f}% {msg}"))
```

## 22. 监督反思模块 (terrain/supervisor/, v9.0 新增)

> 闭环自改进系统：生成 → 审计 → 反思 → 学习日志 → 自动注入低风险 overrides → 再生成。

### 22.1 工作流

```
generate_world 末尾
    ↓
audit_world(dem, lats, seed, size)        # compute_metrics + reflect
    ↓
reflect_and_learn(report, apply_suggestions=True)
    ├─ write_overrides()  → overrides.json   # 低风险项自动注入
    ├─ append_log()       → log.jsonl        # JSONL 学习日志
    ├─ 重建 summary.md                       # 聚合摘要
    └─ 终端打印审计简报
    ↓
下次 generate_world 骨架细化前读 get_overrides() 注入
```

### 22.2 核心 API

```python
from terrain.supervisor import (
    audit_world, reflect_and_learn, get_overrides, reset_overrides,
    query_recent, query_by_metric, aggregate_stats,
)

# 审计一个世界
report = audit_world(dem_m, lats, seed=42, size_px=2048)
# report.metrics  : SupervisorMetrics（七大维度指标）
# report.reflections : List[Reflection]（severity + metric + suggestion）

# 反思 + 学习（可选自动注入 overrides）
reflections = reflect_and_learn(report, apply_suggestions=True)

# generate_world 注入
overrides = get_overrides()   # Dict[str, float]，文件不存在返回 {}
```

### 22.3 Reflection 与 overrides

每个 `Reflection` 含：`metric`（指标名）、`severity`（critical/warn/info/ok）、
`current`/`reference`（当前值 vs 地球参考）、`suggestion`（建议调整）。

`reflector.py` 按规则生成反思，低风险项（如海平面微调、雪线偏移）自动写入
`overrides.json`，下次生成时注入；高风险项仅记录不自动修改。

### 22.4 学习日志 (learning_log.py)

- `log.jsonl`：每行一次审计，含 metrics + reflections + overrides + version
- `summary.md`：聚合统计，自动重建
- 查询 API：`query_recent(n)` / `query_by_metric(metric)` / `aggregate_stats()`

### 22.5 CLI

```bash
# 审计指定种子（生成 + 审计 + 反思）
python -m terrain.supervisor --seed 42 --size-px 2048

# 仅审计不生成（需已有 world_dem.npy）
python -m terrain.supervisor --seed 42 --size-px 2048 --audit-only

# 查看最近 10 条学习日志
python -m terrain.supervisor --history 10

# 清空 overrides（停止自动注入）
python -m terrain.supervisor --reset-overrides
```
