# 幻想世界生成器 v6.5 —— 技术文档

> 使用说明见 [README.md](README.md)。本文档面向算法原理与调参。

## 1. 管线总览

```
板块演化模拟 (plate_sim, 450 Myr)
    ↓  粗DEM + 4构造场 + 陆壳场
周期 fBm 域扭曲 (消 Voronoi 直线感)
    ↓
像素级骨架细化 (海岸分形级联 / 山脉束状 / 盆地)
    ↓
12 通道条件 → 逐瓦片 GAN (UNet) 细节生成
    ↓
全局后处理 (CDF 匹配 → 去斑 → 粒子水力侵蚀 → 填洼 D8 河网)
    ↓
气候因果链渲染 (温度→降水→生物群系 / 河湖 / 雪线 / 海冰)
```

运行（项目根目录）: `python terrain/generate_world.py --seed 0 --size 2048`
板块模拟单独调试: `python terrain/plate_sim.py --seed 7 --T 512`
重训 GAN: `python terrain/terrain_engine.py`（需 data/ 中的 ETOPO1）
重绘（不重算 DEM）: `python terrain/rerender.py`

> 所有路径基于脚本所在目录（terrain/），从任意工作目录调用均有效。

## 2. 板块演化模拟 (plate_sim.py)

### 原理
球面前向模拟：K 个板块各持旋转轴与角速度，每步后向映射搬运地壳（面积守恒）。
按边界两侧地壳类型 + 相对速度法向投影分类赋地形。

### 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `T` | 512 | 模拟分辨率 (格) |
| `K` | 12 | 板块数 |
| `dt × steps` | 0.625 × 720 | 450 Myr 总演化时长 |
| `land_target` | 0.30 | 目标陆地占比 |
| `omg` | U(0.0012, 0.005) rad/步 | 板块角速度 |
| 半球先验 | 85% | 大陆播种偏向随机"陆半球" → 北陆南水型不对称 |

### 边界分类规则
相邻格速度差在边界法向投影 `cn`：
- `cn > 0.35·|v|` 汇聚：陆陆→碰撞造山；洋陆→海沟+火山弧；洋洋→老洋壳俯冲
- `cn < -0.35·|v|` 离散：洋洋→洋中脊；陆陆→裂谷（衰减记忆 ~37 Myr 后裂开）
- 其余 → 转换断层

### 地形赋值（终局装配）
- 洋盆: `-(2600 + 360·√age)`，洋壳年龄截断 55~85 Myr
- 海沟: `-(2400 + 2000·速率)`，贴陆缘
- 火山弧: 2200m 基座 + 4600m 峰值 × 低频门控（弧段链，非圆点）
- 洋中脊: +2300m 宽隆起 − 380m 轴谷
- 碰撞造山: 历史累积 orog → tanh 压缩 → 峰值 ~4900m
- 前陆盆地: 造山带外侧 −620m（山盆成对）

## 3. 域扭曲 + 骨架细化 (generate_world.py)

### 周期 fBm 域扭曲
```
offset = 16·fbm(freq=6, oct=3) + 4·fbm(freq=20, oct=2)   # 单位: 格
```
高程/构造/陆壳三场**同步扭曲**（保持空间一致），经度方向回卷无缝。
→ Voronoi 直线边界变自然弧线，消"细胞壁"感。

### 海岸分形级联（D≈1.3）
海岸带 = `exp(-(|elev|/420m)²)` 内逐级叠加：

| 层级 | 振幅 | 频率 | 效果 |
|------|------|------|------|
| 宏观 | 480m | 连续陆壳场 | 大湾/半岛 |
| 中观 | 300m | f=34 | 岬角/海湾 |
| 细观1 | 150m | f=90 | 岸线弯曲 |
| 细观2 | 85m | f=200 | 碎屑岸 |
| 细观3 | 45m | f=450 | 像素级粗糙 |

### 山脉与盆地
- 山脉: `700m × 构造场 × 宽度变化场(0.25~2.0) × ridged_fbm²`
  （束状分支 + 宽度空间变化，消"贴边条"）
- 山间盆地: `−2000m × 低频噪声(f=10) × 造山带强度`（费尔干纳型）
- 腹地盆地: `−1600m × 距岸>130px × 低频噪声`（刚果/塔里木型）

## 4. GAN 细节生成 (terrain_engine.py)

### 12 通道条件
| # | 通道 | # | 通道 |
|---|------|---|------|
| 0-3 | 块均值/std/min/max | 6 | 冰川占比 |
| 4 | 陆占比 | 7 | 纬度 |
| 5 | 河网 | 8-11 | 构造场(边界/俯冲碰撞/离散/转换) |

### 瓦片拼接
256px 瓦片（32×32 块），重叠 6 块余弦羽化；低频引导对齐拉回块均值；
深海块硬钳制（块均值+0.06）防幻觉浅滩。
检查点: `checkpoints/best_terrain_gan_v5.pth`（UNet in_ch=12, base=32）

## 5. 全局后处理

| 步骤 | 关键参数 |
|------|---------|
| CDF 包络匹配 | blend=0.60，峰值截断 8200m |
| 去斑 | 孤岛/孤湖 <64px 清除 |
| **粒子水力侵蚀** | 15 万水滴，寿命 40 步，惯性 0.10，容量 4.0，侵蚀 0.45/沉积 0.30，蒸发 0.012 → V 形谷/冲积扇/三角洲 |
| 海岸锐化 | 0.5 附近梯度 ×2.4 |
| 填洼 D8 河网 | 形态学填洼（ε=4e-4）→ 流累积 → 河谷下切 0.035·t^0.8 |

## 6. 气候因果链 (terrain_engine.py)

### 温度场
```
T = 27 − 0.42·|lat| − 6.5·(elev/1000) − 22·clip((|lat|−55)/35, 0, 1)²
```
末项为极地放大 → 80° 海平面约 −15°C，极冠自动成雪。

### 降水场
纬向基础（ITCZ 峰 2300mm → 副热带谷 520 → 温带 850 → 极地 130）
× 盛行风向扫描（30°~60° 西风带东向；其余信风/极地东风西向）：
迎风坡地形雨 ≤2600mm，水汽随陆上路径指数衰减
→ **雨影荒漠与大陆腹地干旱自动涌现**。

### Whittaker 生物群系（9 类）
(T, P) 查表: 苔原 / 针叶林 / 温带草原 / 落叶林 / 温带雨林 /
亚热带荒漠 / 稀树草原 / 热带季节林 / 热带雨林

### 雪线（双因素）
- 纬度曲线: 赤道 4800m → **副热带 25° 峰值 5800m**（安第斯型）→ 极地 0m
- 干旱抬升: `+800m × (1 − P/700)`（降水越少雪线越高）
- 温度雪线: 年均温 ≤ −12°C 常年积雪（连续过渡，无硬截断）

## 7. 渲染 (render_world)

| 要素 | 实现 |
|------|------|
| 陆地配色 | 生物群系色 × 海拔明暗 × NW 光照山体阴影 |
| 湖泊 | 填洼面−实际地形 > 0.012 → 深蓝 |
| 河流 | 流累积 > 99.5 分位；干流 (>5×阈值) 加宽更深的蓝 |
| 雪盖 | max(纬度雪线, 温度雪线) × 山脊骨架纹理 |
| 海冰 | 64.5°±2.5° 纬度 + 浮冰噪声 |
